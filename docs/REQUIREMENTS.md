# 요구사항 정의서

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | Doodle & Quiz AI Server MVP |
| 형태 | FastAPI 기반 독립 AI API 서버 |
| 핵심 경험 | 텍스트, 웹페이지, YouTube 자막을 4지선다 문제로 변환하고, 업로드 이미지를 유해성 기준으로 검사 |
| 운영 방향 | 실제 서비스 연동 전 Swagger/curl/Postman으로 API 동작 검증 |

## 2. 문제 정의

- 퀴즈 콘텐츠를 수동 작성하면 반복 작업과 시간이 많이 든다.
- 웹사이트와 YouTube 자료를 문제로 변환하려면 입력 추출, 정제, 문제 생성, 구조화 응답이 필요하다.
- 두들류 서비스에서 이미지를 업로드하려면 유해 이미지 차단 기준이 필요하다.
- AI API 호출은 비용이 발생하므로 문항 수, 입력 길이, 파일 크기 제한이 필요하다.

## 3. 사용 주체

| 주체 | 설명 | 주요 행동 |
|---|---|---|
| 개발자 | AI 서버를 구현하고 API를 검증하는 사용자 | Swagger, curl, Postman 테스트 |
| API 호출 백엔드 | 향후 Quiz/Doodle Backend가 될 호출 주체 | AI 서버 endpoint 호출 |
| 최종 사용자 | MVP에서는 AI 서버를 직접 호출하지 않음 | 범위 밖 |

## 4. MVP 범위

| 구분 | 포함 여부 | 내용 |
|---|---:|---|
| 직접 입력 문제 생성 | 포함 | 사용자가 입력한 설명/본문 기반 문제 생성 |
| 웹사이트 문제 생성 | 포함 | 정적 HTML 본문 추출 후 문제 생성 |
| YouTube 문제 생성 | 포함 | 자막이 있는 경우에만 문제 생성 |
| 이미지 유해성 검사 | 포함 | 이미지 파일 업로드 후 허용/차단 판단 |
| API Key 인증 | 포함 | `X-Internal-Api-Key` header 검증 |
| 생성 횟수 제한 | 제외 | 향후 백엔드 서버에서 사용자 인증 기반 처리 |
| 서비스 실제 연동 | 제외 | MVP에서는 단독 API 검증까지만 진행 |
| DB 저장 | 제외 | AI 서버는 문제/이미지를 저장하지 않음 |
| LangGraph/RAG | 제외 | 검증/재시도/검색 기반 고도화 단계에서 검토 |

## 5. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| AI-FR-001 | 서버는 `/health` endpoint로 상태 확인을 제공해야 한다. | 상 |
| AI-FR-002 | 서버는 직접 입력 텍스트 기반 문제 생성 API를 제공해야 한다. | 상 |
| AI-FR-003 | 서버는 웹사이트 URL 기반 문제 생성 API를 제공해야 한다. | 상 |
| AI-FR-004 | 서버는 YouTube 자막 기반 문제 생성 API를 제공해야 한다. | 상 |
| AI-FR-005 | 모든 문제 생성 결과는 한국어 4지선다 3문항이어야 한다. | 상 |
| AI-FR-006 | 정답은 각 문항의 1번 보기에 위치하고 `answer_index`는 0이어야 한다. | 상 |
| AI-FR-007 | 난이도는 `beginner`, `intermediate`, `advanced` 중 하나로 검증해야 한다. | 중 |
| AI-FR-008 | 문제 생성 실패 또는 출력 schema 오류 시 1회 재생성을 시도해야 한다. | 중 |
| AI-FR-009 | 서버는 이미지 유해성 검사 API를 제공해야 한다. | 상 |
| AI-FR-010 | 유해 이미지로 판단되면 저장하지 않고 차단 결과를 반환해야 한다. | 상 |
| AI-FR-011 | 서버는 공통 error code와 message 형식으로 실패 응답을 반환해야 한다. | 중 |

## 6. 비기능 요구사항

| 구분 | 요구사항 |
|---|---|
| 성능 | URL fetch와 외부 API 호출에는 timeout을 적용한다. 문제 생성은 동기 응답을 기본으로 한다. |
| 보안 | `X-Internal-Api-Key`가 없거나 일치하지 않으면 요청을 거부한다. API Key와 외부 모델 Key는 로그에 남기지 않는다. |
| 안정성 | AI 응답이 schema를 벗어나면 1회 재생성 후 실패 응답을 반환한다. |
| 확장성 | MVP는 stateless 서버로 구성하고, 생성 횟수 제한과 DB 저장은 외부 백엔드로 위임한다. |
| 호환성 | Swagger UI, curl, Postman으로 API 검증이 가능해야 한다. |
| 운영성 | Dockerfile을 제공하고 환경변수 기반으로 모델명, API Key, 제한값을 관리한다. |

## 7. 제외 범위

- 프론트엔드와의 직접 통신
- Quiz Service/Doodle Service 실제 연동
- 사용자 인증과 사용자별 생성 횟수 제한
- DB 저장, 로그 DB, 관리자 화면
- Socket.IO, 실시간 스트리밍 응답
- YouTube 음성 다운로드, Whisper 음성 인식
- PDF 문서 추출, 동적 렌더링 웹페이지 처리
- LangGraph, RAG, 벡터 DB
