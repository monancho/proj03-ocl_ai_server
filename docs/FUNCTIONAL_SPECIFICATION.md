# 기능 명세서

## 1. 기능 목록

| 기능 ID | 기능명 | 설명 | 우선순위 |
|---|---|---|---|
| AI-F-001 | 직접 입력 문제 생성 | 본문/설명 텍스트로 3문항 생성 | 상 |
| AI-F-002 | 웹사이트 문제 생성 | URL 본문 추출 후 3문항 생성 | 상 |
| AI-F-003 | YouTube 문제 생성 | 자막 텍스트로 3문항 생성 | 상 |

| AI-F-005 | 내부 API Key 인증 | 허용된 호출만 처리 | 상 |
| AI-F-006 | 공통 오류 처리 | code/message 기반 오류 반환 | 중 |

## 2. 문제 생성 공통 규칙

| 항목 | 정책 |
|---|---|
| 문제 유형 | 4지선다 객관식만 지원 |
| 문항 수 | 항상 3문항 생성. `question_count` 입력은 받지 않음 |
| 언어 | 문제, 보기, 해설은 한국어로 생성 |
| 정답 위치 | 항상 1번 보기. `answer_index`는 0으로 고정 |
| 난이도 | `beginner`, `intermediate`, `advanced` 중 하나 |
| 해설 | 각 문항마다 1~2문장 수준의 해설 포함 |
| 생성 실패 | schema 오류, 문항 수 오류, 정답 위치 오류가 있으면 1회 재생성 |
| 생성 횟수 제한 | AI 서버에서 구현하지 않음. 향후 서비스 백엔드 책임 |

## 3. 직접 입력 문제 생성

처리 흐름:

```text
사용자 본문 입력
↓
AI Server 입력 길이 검증
↓
문제 생성 모델 호출
↓
구조화 결과 검증
↓
3문항 JSON 반환
```

검증 기준:

| 검증 대상 | 규칙 | 실패 코드 |
|---|---|---|
| `content` | 필수 문자열, trim 후 최소 100자 권장 | `SOURCE_TEXT_TOO_SHORT` |
| `content` | 최대 12,000자 | `SOURCE_TEXT_TOO_LONG` |
| `difficulty` | `beginner`/`intermediate`/`advanced` 중 하나 | `DIFFICULTY_INVALID` |

## 4. 웹사이트 기반 문제 생성

처리 흐름:

```text
웹사이트 URL 입력
↓
URL 형식 검증
↓
정적 HTML fetch
↓
본문 추출 및 텍스트 정제
↓
12,000자 제한 적용
↓
문제 생성 및 JSON 반환
```

정책:

- 일반 웹페이지 HTML만 지원한다.
- PDF, 로그인 필요 페이지, 동적 렌더링 필수 페이지는 MVP에서 제외한다.
- 본문이 12,000자를 초과하면 warning을 포함하고 앞부분 12,000자만 사용한다.
- 본문 추출에 실패하면 `WEB_CONTENT_EXTRACT_FAILED`를 반환한다.

## 5. YouTube 기반 문제 생성

처리 흐름:

```text
YouTube URL 입력
↓
YouTube URL 검증
↓
자막 존재 여부 확인
↓
자막 텍스트 추출
↓
12,000자 제한 적용
↓
문제 생성 및 JSON 반환
```

정책:

| 항목 | 정책 |
|---|---|
| 자막 기준 | 자막이 있는 영상만 처리한다. 자막이 없으면 오류 반환 |
| 음성 추출 | MVP 제외 |
| Whisper | MVP 제외 |
| 영상 길이 | 20분 이하 권장. 강제 차단은 구현 단계에서 결정 가능 |
| 긴 자막 | 12,000자 초과 시 warning 포함 후 앞부분 12,000자 사용 |
| 출력 언어 | 자막 언어와 무관하게 한국어 문제로 반환 |

## 6. 이미지 유해성 검사

처리 흐름:

```text
이미지 파일 업로드
↓
MIME/확장자/크기 검증
↓
Moderation API 호출
↓
risk_level 계산
↓
allowed true/false 반환
```

정책:

| 항목 | 정책 |
|---|---|
| 허용 형식 | jpg, jpeg, png, webp |
| 파일 크기 | 5MB 이하 |
| 저장 여부 | AI 서버는 원본 이미지를 저장하지 않음 |
| low | 허용 |
| medium | 차단 |
| high | 차단 |
| 사용자 메시지 | 업로드할 수 없는 이미지입니다. 다른 이미지를 선택해 주세요. |

## 7. 문제 품질 기준

- 문항은 원문 또는 추출 텍스트에서 근거를 찾을 수 있어야 한다.
- 보기는 4개이며 의미상 중복되지 않아야 한다.
- 정답은 반드시 첫 번째 보기여야 한다.
- 문항 3개가 서로 지나치게 유사하면 실패로 본다.
- 해설은 정답 근거를 짧게 설명해야 하며 원문에 없는 사실을 만들지 않는다.

## 8. 예외 처리

| 상황 | 처리 방식 | 사용자 메시지 방향 |
|---|---|---|
| API Key 누락/불일치 | 401 응답 | 허용되지 않은 요청입니다. |
| 본문이 너무 짧음 | 400 응답 | 문제 생성에 사용할 내용이 부족합니다. |
| 웹 본문 추출 실패 | 422 응답 | 해당 페이지에서 문제 생성용 본문을 추출할 수 없습니다. |
| YouTube 자막 없음 | 422 응답 | 이 영상에는 사용할 수 있는 자막이 없습니다. |
| 이미지 형식 오류 | 415 응답 | 지원하지 않는 이미지 형식입니다. |
| AI 생성 실패 | 1회 재시도 후 502 응답 | 문제 생성 중 오류가 발생했습니다. |
